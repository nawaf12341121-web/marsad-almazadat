# جامع مرصد المزادات — عبدالله فؤاد

هذا أول جامع تجريبي للمصدر. يعمل بوضع **المعاينة فقط**:

- يقرأ صفحة المزادات العامة.
- يلتقط روابط صفحات المزادات.
- يفتح صفحات التفاصيل ويحاول استخراج العنوان والوصف والموقع وتاريخ النشر.
- يحفظ النتائج في ملف JSON للمراجعة.

## الأمان

- لا يتصل بـ Supabase.
- لا يضيف أو يعدّل أو يحذف أي سجل.
- لا ينشر شيئًا على موقع مرصد المزادات.
- كل نتيجة تحمل الحقل `review_required: true` وتحتاج مراجعة قبل اعتمادها.

## التشغيل على جهازك

يتطلب Python 3.10 أو أحدث:

```bash
cd collector
python -m pip install -r requirements.txt
python preview_abdullah_fouad.py
```

سيُنشئ الملف `abdullah_fouad_preview.json` في المجلد نفسه.

يمكن تعديل مهلة الطلبات:

```bash
python preview_abdullah_fouad.py --delay 2
```

## ملاحظة

هذا اختبار أولي لبنية صفحة المصدر الحالية. إذا غيّر الموقع تصميمه فقد يحتاج الجامع إلى تحديث. لا توجد جدولة تلقائية أو ربط بقاعدة البيانات في هذه المرحلة.
